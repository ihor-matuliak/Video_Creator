# ClipForge Local — пакет реалізації для Claude Code

Версія пакета: 1.0. Дата: 12 листопада 2026 року. Мова продукту: українська.

Цей пакет містить технічне завдання та матеріали для створення персонального Windows-застосунку: локальне відео → транскрипція → вибір категорій → кандидати → перегляд і коригування → окремі MP4. Це пакет для розробки, а не готова програма.

## З чого почати

1. Розпакувати весь архів у нову папку проєкту. Зберегти папку `.claude` та решту структури.
2. Відкрити цю папку в локальному Claude Code. Для цього пакета основний сценарій — локальна сесія, яка має доступ до файлів і FFmpeg.
3. Прочитати `docs/01_SPEC.md` та `docs/02_IMPLEMENTATION_PLAN.md`.
4. Передати Claude Code весь текст із `START_HERE.md`.
5. Виконувати етапи M0–M8 послідовно. Після кожного етапу перевіряти його критерії виходу та оновлювати `docs/PROGRESS.md`.

## Необхідне від власника

- Windows 11 x64 для першого релізу; фактичні CPU, RAM, GPU і вільний диск записати в M0.
- Локальний відеофайл із правом на обробку. Для першої перевірки достатньо 10–20 хвилин; для приймання потрібен і довгий запис.
- Обліковий запис OpenRouter, API-ключ і обраний ліміт витрат. Ключ вводиться локально, не в чат і не в Git.
- Мови записів та приклади 10–20 бажаних / небажаних моментів для калібрування. Відсутність розмітки не блокує технічну реалізацію.
- Доступ розробника до Claude Code. Його оплата та оплата OpenRouter є окремими витратами.

## Що підготує Claude Code

За M0 перевірити інструменти, зафіксувати сумісні версії у lock-файлах, перевірити реальний контракт провайдера на короткому аудіо за наявності ключа. Далі створити застосунок, виконати тести, сформувати Windows-пакет, інструкцію користувача та звіт про приймання. Автоматизовані тести за замовчуванням працюють з локальними підставними відповідями та не витрачають баланс API.

## Межа перевіреності

Тести програми в цьому пакеті задають очікувану поведінку. Вони не можуть підтвердити працездатність ще не реалізованого застосунку. `VALIDATION_REPORT.md` окремо фіксує перевірки пакета, тестових файлів і медіафікстур. Не змішувати ці результати з проходженням приймання продукту.
